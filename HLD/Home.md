## 設計方針

| # | 方針 |
| :--- | :--- |
| 1 | Northwind 原典のテーブル構造を保持する。追加は楽観排他用の `RowVersion` 列と `SalesTargets` テーブルのみ（[共通仕様 9 節](./Common.md#9-northwind-原典への追加)） |
| 2 | 特定のフレームワークに依存しない用語で記述する |
| 3 | サンプルとして過剰な設計（ワークテーブル・採番テーブル・変更履歴・論理削除・非同期処理・キャッシュ・DDD）を行わない（[共通仕様 1 節](./Common.md#設計スコープ作らないもの)） |
| 4 | 共通で決まる事柄は[共通仕様](./Common.md)に集約し、各成果物からは ID で参照する |
