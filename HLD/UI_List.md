全 9 モジュールの画面を画面 ID 単位で列挙する。画面項目とイベントの定義は [画面定義書](../LLD/UI_ElementsAndEventList.md) を参照。

## 凡例

| 欄 | 内容 |
| :--- | :--- |
| 画面 ID | `SC-<モジュールコード>-<連番>` |
| 種別 | 一覧／詳細／ダイアログ／ツリー／ダッシュボード／帳票 |
| モード | 当該画面が取り得るモード（[共通仕様 4 節](./Common.md#4-共通画面仕様)） |
| 遷移パラメータ | 遷移元から引き渡される値 |
