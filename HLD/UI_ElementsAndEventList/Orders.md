# 画面定義書：受注管理

[画面定義書 索引](../UI_ElementsAndEventList.md) ／ [イベント仕様書](../EventSpec/Orders.md) ／ [共通仕様](../Common.md) ／ [画面一覧](../UI_List.md) ／ [テーブル定義書](../TableSchema/Orders.md)

対象画面：`SC-ORD-01` 〜 `SC-ORD-05`

本書は画面ごとに「画面項目」「アクションボタン」「イベント一覧」を定義する。
各イベントの処理内容は [イベント仕様書](../EventSpec/Orders.md) を参照。

## 凡例

| 欄 | 内容 |
| :--- | :--- |
| 項目 ID | `<画面ID>-I<連番>` |
| ボタン ID | `<画面ID>-B<連番>` |
| 種別 | ラベル（表示のみ）／テキスト／数値／日付／ドロップダウン／チェック／表 |
| 入出力 | `入` = 利用者が入力、`出` = 表示のみ、`入出` = 初期値を表示し利用者が変更可 |
| データソース | `テーブル.列` または算出式 |

金額の算出式は[共通仕様 3 節](../Common.md#金額の算出式)に従う。
`RowVersion` は楽観排他のために画面が内部保持するが、画面項目としては表示しない。

# SC-ORD-01 受注一覧画面

受注を検索条件で絞り込み、ページ単位に一覧表示する。受注管理モジュールの入口。

## 画面項目

### 検索条件

| 項目 ID | 表示名 | 種別 | 入出力 | 必須 | データソース | 制約・備考 |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| `SC-ORD-01-I01` | 顧客 | ドロップダウン | 入 | － | `Customers.CustomerID` / `CompanyName` | 会社名の昇順。先頭に空白の選択肢（＝すべて）を置く |
| `SC-ORD-01-I02` | 担当者 | ドロップダウン | 入 | － | `Employees.EmployeeID` / `LastName + " " + FirstName` | 姓・名の昇順。先頭に空白の選択肢（＝すべて）を置く |
| `SC-ORD-01-I03` | 受注日（開始） | 日付 | 入 | － | 検索条件 | `yyyy/MM/dd`。当該日を含む |
| `SC-ORD-01-I04` | 受注日（終了） | 日付 | 入 | － | 検索条件 | `yyyy/MM/dd`。当該日を含む。開始 <= 終了であること |
| `SC-ORD-01-I05` | 出荷状況 | ドロップダウン | 入 | － | 固定値 | 「すべて（既定）」「未出荷」「出荷済」「納期遅延」 |

# SC-ORD-03 受注詳細画面（登録・編集）

受注情報と明細を入力して保存する。登録モードと編集モードの差分は各項目の備考に示す。

## 画面項目

### 受注情報

| 項目 ID | 表示名 | 種別 | 入出力 | 必須 | データソース | 制約・備考 |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| `SC-ORD-03-I01` | 受注 ID | ラベル | 出 | － | `Orders.OrderID` | 登録モードでは「（登録時に採番）」と表示 |
| `SC-ORD-03-I02` | 顧客＊ | ドロップダウン | 入出 | ○ | `Customers.CustomerID` / `CompanyName` | 会社名の昇順。変更で `EV-ORD-302` が発火 |
| `SC-ORD-03-I03` | 顧客電話番号 | ラベル | 出 | － | `Customers.Phone` | `SC-ORD-03-I02` の選択に連動 |
| `SC-ORD-03-I04` | 顧客住所 | ラベル | 出 | － | `Customers.Address` + `City` + `Region` + `PostalCode` + `Country` | `SC-ORD-03-I02` の選択に連動 |
| `SC-ORD-03-I05` | 担当者＊ | ドロップダウン | 入出 | ○ | `Employees.EmployeeID` / `LastName + " " + FirstName` | 姓・名の昇順 |
| `SC-ORD-03-I06` | 受注日＊ | 日付 | 入出 | ○ | `Orders.OrderDate` | 登録モードの初期値は当日 |
| `SC-ORD-03-I07` | 要求納期 | 日付 | 入出 | － | `Orders.RequiredDate` | `受注日 <= 要求納期`（`VAL-DATE`） |
| `SC-ORD-03-I08` | 配送業者 | ドロップダウン | 入出 | － | `Shippers.ShipperID` / `CompanyName` | 会社名の昇順。先頭に空白の選択肢を置く |
| `SC-ORD-03-I09` | 送料 | 数値 | 入出 | － | `Orders.Freight` | 0 以上（`VAL-NUMERIC`）。既定値 0。変更で `EV-ORD-303` が発火 |

出荷日（`Orders.ShippedDate`）は本画面では変更しない。出荷ステータス更新ダイアログ（`SC-ORD-04`）で更新する。

| `SC-ORD-03-I12` | 出荷先市区町村 | テキスト | 入出 | － | `Orders.ShipCity` | 15 文字以内 |

### 受注明細情報

| 項目 ID | 表示名 | 種別 | 入出力 | 必須 | データソース | 制約・備考 |

# SC-ORD-04 出荷ステータス更新ダイアログ

受注 1 件の出荷日・配送業者・送料を設定し、出荷を確定または取り消す。
`SC-ORD-01` / `SC-ORD-02` / `SC-SHP-04` から呼び出される。

## 画面項目

| 項目 ID | 表示名 | 種別 | 入出力 | 必須 | データソース | 制約・備考 |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| `SC-ORD-04-I01` | 受注 ID | ラベル | 出 | － | `Orders.OrderID` | |
| `SC-ORD-04-I02` | 顧客名 | ラベル | 出 | － | `Customers.CompanyName` | |
| `SC-ORD-04-I03` | 現在の状況 | ラベル | 出 | － | 算出 | 「未出荷」「出荷済」「納期遅延」（ORD-T7） |
| `SC-ORD-04-I04` | 要求納期 | ラベル | 出 | － | `Orders.RequiredDate` | 遅延の判断材料として表示 |
| `SC-ORD-04-I05` | 出荷日＊ | 日付 | 入出 | ○ | `Orders.ShippedDate` | 未出荷のときの初期値は当日。`受注日 <= 出荷日`（`VAL-DATE`） |
| `SC-ORD-04-I06` | 配送業者＊ | ドロップダウン | 入出 | ○ | `Shippers.ShipperID` / `CompanyName` | 会社名の昇順 |
| `SC-ORD-04-I07` | 送料 | 数値 | 入出 | － | `Orders.Freight` | 0 以上（`VAL-NUMERIC`） |
| `SC-ORD-04-I08` | 在庫引落の内訳 | 表 | 出 | － | 明細の商品名・数量・現在庫数 | 未出荷から出荷確定するときのみ表示。在庫が不足する行を強調表示する |
