詳細：[テーブル定義書](./TableSchema.md) / [画面定義書](./UI_ElementsAndEventList.md) / [イベント仕様書](./EventSpec.md) / [決定記録](./Decisions.md) / **実装の記録**

本書は、**仕様が決めていない部分（実装の自由度）を、実装がどう作ったか**を残すメモの索引である。

## 読み方

- **実装入力ではない。** 本書以下は、ある実装が選んだことの記録で、仕様ではない。ほかの実装は、ここに書かれた形に合わせなくてよい。
  実装・テストの入力は、本文と[決定記録](./Decisions.md)である（[詳細設計](./Home.md)「実装に着手する前に読むもの」）。
- 決定記録・本文と食い違うときは、決定記録・本文を正とし、実装の側を直す。
- 書くもの：
  1. 決定記録で「定めない」とした点を、実装がどう作ったか（`IMP-<MOD>-nn`。`nn` は対応する `DEC-<MOD>-nn` と同じ番号）。
  2. 仕様が文言を決めていないメッセージの実際の文言と、メッセージ ID（[DEC-CMN-01](./Decisions/Common.md#dec-cmn-01-メッセージの定め方)：ID は実装で決める）。
  3. 仕様の問いにしなかった実装の決定（状態の持ち方・トランザクションの分離レベル・画面の作りなど。`IMP-<MOD>-Xnn`）。
- 記録は「確かめた事実」と「確かめていない見込み」を分けて書く。見込みには「確かめていない」と書く。
- 実装を直したら、ここも直す（どの版の実装の記録かを、各ファイルの冒頭に書く）。

## 記載項目

1 件につき 1 節を設け、見出しは `IMP-<MOD>-nn <名前>` とする。

| 項目 | 内容 |
| :--- | :--- |
| 対象 | 対応する決定（`DEC-*`）・本文の ID |
| 実装 | 実装の振る舞い。ケースで違えばケースごとに書く（ケース 1：MVC_Sample〔net48〕、ケース 2：MVC_Sample_Core〔net10.0〕、ケース 3：WebForms_Sample） |
| 場所 | 実装のファイル（リポジトリの中のパス。行番号は書かない：ずれるため、メソッド名・定数名で引く） |
| テスト | テストの期待にしているか（「定めない」は、ふつう期待にしていない） |
