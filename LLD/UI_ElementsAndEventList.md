## 共通ルール

### 記載形式

各画面は次の 3 節で記述する。

| 節 | 内容 |
| :--- | :--- |
| 画面項目 | `項目ID / 表示名 / 種別 / 入出力 / 必須 / データソース / 制約・備考` |
| アクションボタン | `ボタンID / 表示名 / 配置 / 活性条件 / 発火イベント` |
| イベント一覧 | `イベントID / イベント名 / トリガー / 概要`（イベント仕様書へのリンクを張る） |

表が画面項目に含まれる場合は、直後に列定義の表（`列 / 表示名 / データソース / 備考`）を続ける。

### ID の付番

| 種別 | 書式 | 例 |
| :--- | :--- | :--- |
| 画面項目 | `<画面ID>-I<2 桁連番>` | `SC-ORD-01-I01` |
| アクションボタン | `<画面ID>-B<2 桁連番>` | `SC-ORD-01-B01` |

連番は画面内で通し番号とし、節をまたいでも重複させない。項目の追加は末尾に採番し、既存の番号を詰め直さない。

### 記載の約束

| # | 約束 |
| :--- | :--- |
| 1 | 特定のフレームワークのコントロール名・API 名を用いない。「一覧表」「ドロップダウン」「日付」等の一般語で記述する |
| 2 | データソースは `テーブル.列` または算出式で示す。「顧客の情報」のような曖昧な記述をしない |
| 3 | 算出項目は必ず式を示す（[共通仕様 3 節](../HLD/Common.md#金額の算出式)の定義を用いる） |
| 4 | 必須項目は表示名の末尾に「＊」を付し、必須欄を「○」とする |
| 5 | `RowVersion` は画面項目に含めない（画面が内部保持する旨をイベント仕様書に記す） |
| 6 | 全画面に共通する仕様（ページング・並べ替え・メッセージ表示・確認ダイアログ）は[共通仕様 4 節](../HLD/Common.md#4-共通画面仕様)に従い、差分のみを記述する |
| 7 | 共通イベント（メニューへ戻る）はイベント一覧に再掲しない（[共通仕様 8 節](../HLD/Common.md#8-共通イベント)） |
| 8 | 画像列（`Photo` / `Picture`）は表示・更新の対象外とし、画面項目に含めない |
